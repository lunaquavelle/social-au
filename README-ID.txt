SOCIAL AU STARTER — PANDUAN PEMULA
===================================

ISI FOLDER
- index.html  : struktur halaman website
- styles.css  : warna, layout, dan tampilan responsive
- data.js     : ISI CERITA, karakter, postingan, dan chat contoh
- app.js      : fungsi untuk menampilkan konten dan navigasi

CARA MELIHAT WEBSITE DI KOMPUTER (TANPA CODING)
1. Download dan ekstrak file ZIP.
2. Buka folder social-au-starter.
3. Klik dua kali index.html.
4. Website akan terbuka di browser. Internet diperlukan untuk memuat font Google; layout tetap berfungsi jika offline.

CARA MENGGANTI CERITA
1. Klik kanan file data.js lalu pilih Open with > Notepad (atau editor teks).
2. Cari bagian AU_DATA.
3. Ganti nama, username, bio, postingan, angka likes/replies, dan isi chat contoh.
4. Jangan hapus tanda kutip, koma, kurung kurawal, atau kurung siku.
5. Simpan file, lalu refresh halaman browser.

CATATAN:
- Ini adalah template demo dengan konten contoh, bukan akun media sosial sungguhan.
- Tombol navigasi dan perpindahan tab chat berfungsi. Likes/replies hanya tampilan dekoratif.
- Semua konten sudah ditulis author (prewritten). Pembaca tidak mengirim pesan atau komentar.
- Untuk keamanan, masukkan hanya konten yang memang ingin dipublikasikan.

CARA HOSTING GRATIS DI NETLIFY (DRAG & DROP)
1. Buka https://app.netlify.com/drop
2. Login atau buat akun Netlify.
3. Ekstrak ZIP terlebih dahulu di komputer.
4. Seret folder social-au-starter (folder yang berisi index.html, styles.css, data.js, app.js) ke area upload Netlify.
5. Tunggu proses selesai. Netlify akan memberikan alamat website berakhiran netlify.app.
6. Buka alamat tersebut untuk mengecek website.

UPDATE SETELAH EDIT
- Edit file lokal, simpan.
- Upload ulang folder website ke Netlify Drop untuk menerbitkan versi terbaru.
- Simpan file ZIP asli sebagai backup.

TIPS
- Ubah judul "AFTERHOURS" dan teks banner di index.html.
- Ubah warna utama dengan mengganti --accent di bagian atas styles.css.
- Gunakan nama karakter fiktif dan gambar yang kamu punya izin untuk pakai.
